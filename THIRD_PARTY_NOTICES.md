Downloaded bytes and proportions are retained without repainting, upscaling, or transcoding. The TMS `.jpg` URL actually returned WebP and is now stored with the correct `.webp` extension; JPEG files use the image/jpeg MIME type. The [scene stylesheet](src/haibara-scene.css) embeds original bytes with the correct MIME type, without runtime requests to third parties. Crop positions, interface overlays, and visibility strengths are CSS only.

`dsh-workbench-shell` owns the images, palette, scene picker, credit, and `workbench-shell` settings. Native UI, Settings, and the prototype workbench share one state. Legacy `scene-2` / `scene-3` IDs remain valid but now select “Light in the lenses” / “Reaching out”; the older 2001/2014 work images have been removed from product assets and styles. Background changes do not alter the prototype inside its independent preview document.
